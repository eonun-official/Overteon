# Overteon 使用说明书

版本 0.9.20

---

## 欢迎您使用 Overteon

这是一款把侧链均衡、饱和、谐波提取与后置均衡放进同一条信号拓扑的音频效果器。

您大概见过不少饱和插件：把一个信号推进非线性曲线，然后按比例混回干声。这样做当然有效，但结果是音色跟着一起变了——您想要的是厚度，拿到的却是一个新的声音。

Overteon 换了一个思路。它先用一条均衡决定饱和器听到什么，再从饱和结果里只取出新产生的谐波，把这一层叠回您的干声。干声本身没有被均衡，也没有被染色，它只是变得更厚、更有空气感、更有颗粒。

您可以把它当作一台常规饱和器使用，也可以只取它最独特的那一面：只加谐波，不改音色。

---

## 1　概述

### 1.1　用途

Overteon 是音频效果插件，将侧链均衡、饱和、谐波提取与后置均衡置于同一条信号拓扑中，可作为常规饱和器使用，也可仅将新产生的谐波叠加至干声。

### 1.2　信号流

信号在插件内分为两路。

干声支路保持原样，不经过侧链均衡，也不经过其反向均衡。

谐波支路依次经过侧链均衡、过采样饱和、谐波提取与去强调，然后与干声支路求和，最后经过后置均衡与输出级。

两路在求和点之前保持延迟对齐。

### 1.3　基本关系

输出等于干声，加上谐波层乘以叠加量。

由此可知，HARMONICS 控制谐波层的叠加量，DRIVE 控制谐波层自身的强度。

默认工作模式为 HARMONIC。

> 注　侧链 EQ 改变的是谐波层的频率分布，不是干声的频率响应。

---

## 2　三种工作模式

模式由底部的 MODE 选择。三者之间的差别是拓扑，不是预设强度——切换模式会真正改变信号经过哪些环节，这也是 Overteon 值得您花几分钟熟悉的地方。

### 2.1　HARMONIC（默认）

侧链 EQ 与后置 EQ 均参与，干声原样保留。

谐波支路经过侧链均衡、过采样饱和、谐波提取与去强调，再与对齐的干声相加。

此模式中 HARMONICS 表示谐波层的叠加量。这是 Overteon 的核心模式，您想要的加厚但不改音色，就在这里。

### 2.2　CLASSIC

输入直接进入饱和器，按 HARMONICS 与干声混合，再经过后置 EQ。

侧链 EQ 不参与处理，面板置灰。此模式中 HARMONICS 表示湿声与干声的混合比。

需要一台用起来顺手的常规饱和器时，选它。

### 2.3　SCHRANZ

输出为侧链 EQ 之后、饱和器之前的信号。饱和器与后置 EQ 均不参与，面板置灰。

本模式不产生新谐波，谐波比例无定义，谐波环显示 N/A。

> 注　HARM GAIN、DE-EMPH、AIR PROTECT 与 SOLO HARM 仅在 HARMONIC 模式下作用于谐波支路。

## 3　界面导览

界面自上而下分为五个区域。

最上方是表头，包含名称标识、BYP、A/B 与 INIT。

其下是侧链 EQ 区，包含五个节点、实时频谱与量程选择。

中部是谐波环与四路电平表。谐波环同时作为显示设置的入口，详见 4.5。

再往下是后置 EQ 区，结构与侧链 EQ 相同，右侧另有输出限制器的模式与过采样选择。

最下方是底台，包含八个旋钮，以及模式与饱和过采样选择。

## 4　操作

### 4.1　旋钮

上下拖动可连续调整，向上增大。

滚轮每格约移动行程的百分之四；离散参数每格切换一项。

按住 Shift 拖动或滚动为细调，步长约为常态的四分之一。

双击恢复该参数的默认值。

> 注　滚轮仅在指针位于旋钮圆环上时生效，不会误动旁边相邻的旋钮。

### 4.2　下拉菜单与开关

单击展开选项，单击选项完成选择。开关类控件单击即切换。

### 4.3　均衡器节点

拖动节点改变频率；Bell 与 Shelf 类的节点同时改变增益。

滚轮改变 Q 值，按住 Shift 滚轮以细步改变。

指针悬停于节点时打开数值编辑框，可直接键入数值。

双击节点切换该带的开关状态。

双击空白画布，在该频率位置启用一个尚未使用的节点。

右键节点打开该带菜单，可更改类型或移除该带。

> 注　Cut 与 Notch 类节点没有增益，拖动时仅改变频率。

### 4.4　表头

BYP 旁通整个插件。

A/B 为两个独立按钮，同时常显。左键选中该槽，右键将该槽内容复制到另一槽。

INIT 将全部参数复位为默认值。

名称标识悬停显示提示，单击打开关于面板。

A/B 两槽各存一份完整参数快照，切换为互相比较，非单向递进。调参时请善用它——判断一个改动是否有益，最快的方法永远是跟另一个版本比。

### 4.5　显示设置

指针悬停于中央谐波环时，环体转为绿色，百分比文字替换为 SETTINGS；此时单击打开显示设置面板。

面板内对三个表分别设置检波方式与插值方式。

检波方式可选 RMS 或 TRUE PEAK。

插值方式可选 SMOOTH 或 NONE。

> 注　以上为显示设置，不参与音频处理，因此不作为可自动化参数暴露给宿主。

## 5　参数参考

### 5.1　全局

- Bypass 为开关，默认关闭。
- Input Gain 范围 −24 至 +24 dB，默认 0 dB。
- Output Gain 范围 −24 至 +24 dB，默认 0 dB。
- Auto Gain 为开关，默认关闭。
- Stereo Mode 可选 Stereo、Mid、Side 或 M/S，默认 Stereo。

### 5.2　饱和

- Drive 范围 0.00 至 10.00，默认 0.00。
- Drive Type 可选 Tanh、Tube 或 Tape，默认 Tanh。
- Oversampling 可选 2x、4x、8x、16x 或 32x，默认 4x。

三种饱和类型为插件内不同的非线性曲线，并非对特定硬件的建模。Tanh 平滑对称；Tube 含不对称成分，与 Even/Odd 配合使用；Tape 较柔和，瞬态收束。

### 5.3　谐波

- Harmonics Mix 范围 0 至 100%，默认 100%。
- Even / Odd 范围 −100% 至 +100%，默认 0%。负值偏偶次谐波，正值偏奇次谐波，居中原样。
- Harmonics Gain 范围 −12 至 +24 dB，默认 0 dB。
- De-Emphasis 范围 0 至 100%，默认 100%，为可逆侧链节点的反向均衡程度。
- Air Protect 范围 2 kHz 至 20 kHz，默认关闭。该项仅对谐波支路做低通，不作用于干声，您的高频空气感因此得以保留。
- Solo Harmonics 为开关，默认关闭。打开后关闭干声支路，仅输出谐波层，是检查谐波内容的直接手段。

### 5.4　均衡器

侧链 EQ 与后置 EQ 各五带，每带五个参数。

- Freq 范围 5 Hz 至 20 kHz，默认值见附录 B。
- Gain 范围 −12 至 +12 dB，默认 0 dB。
- Q 范围 0.1 至 6.0，默认 0.707。
- Type 可选八种，详见 6.1，默认值见附录 B。
- On 为开关，默认开启。

### 5.5　量程

- SC EQ Range 可选正负 12、24、48 或 90 dB，默认正负 12 dB。
- Post EQ Range 可选正负 3、6、12 或 30 dB，默认正负 12 dB。

### 5.6　限制器

- Limiter Mode 可选 Off、Clip、Modern 或 True Peak，默认 Modern。
- Limiter Oversampling 可选 2x、4x、8x 或 16x，默认 4x。

> 注　全部六十九个参数的完整构成见附录 A。可自动化参数的数量与索引为插件接口的组成部分，新参数一律追加在既有参数之后，因此旧工程不会错位。

## 6　均衡器

### 6.1　类型

Bell 为峰值型。

Notch 为窄带衰减。

Low Shelf 与 High Shelf 分别为低架与高架。

Low Cut 12 与 Low Cut 24 分别为 12 dB/oct 与 24 dB/oct 低切。

High Cut 12 与 High Cut 24 分别为 12 dB/oct 与 24 dB/oct 高切。

任一节点可设为任一类型，频率范围覆盖全频段。每带另带独立开关，关闭的节点以空心绘制，其频率、增益、Q 与类型均保留，重新开启即恢复原状态。

### 6.2　侧链 EQ

在 HARMONIC 模式下，侧链 EQ 决定饱和器的输入频率分布。提升某频段将增加该频段产生的谐波量，衰减则减少。

请留意这一点：您在侧链 EQ 上做的塑形，听见的是谐波的颜色变化，不是干声的频响变化。这是 Overteon 与其他饱和器最不一样的地方，也是它最值得玩的地方。

> 注　高 Q 值配大幅衰减时出现振铃，为滤波器响应的固有性质。需要避免时降低 Q 值，或改用 Shelf 与 Cut 类型。

### 6.3　后置 EQ

作用于求和之后的完整信号，用于最终修整。

CLASSIC 与 HARMONIC 模式下有效，SCHRANZ 模式下不参与。

---

## 7　立体声与过采样

### 7.1　立体声模式

Stereo 为左右声道分别处理。

Mid 仅保留处理后的中央成分，两侧回退至干声。

Side 仅保留处理后的两侧成分，中央回退至干声。

M/S 使中央与两侧均在 M/S 域处理后解码。

处理人声、底鼓、贝斯时，Mid 常常比任何均衡都有效——它让您只给中央加厚度，两侧原封不动。

### 7.2　饱和过采样

可选 2x、4x、8x、16x 或 32x，默认 4x。

倍率越高，混叠越低，延迟与运算量越大。切换后插件向宿主更新延迟报告，宿主需启用延迟补偿。

> 注　饱和过采样为本机全局偏好，不属于预设内容。加载预设不改变当前选择。

---

## 8　输出限制器

限制器位于后置 EQ、输出增益与 Auto Gain 之后。

Off 为完全旁通，无附加延迟。此时输出不再保证低于 0 dBFS。

Clip 为软膝削波，−1 dBFS 起弯，上限 0 dBFS，无附加延迟。

Modern 为 1.5 ms 前瞻，程序相关释放，附加延迟为 1.5 ms 加过采样延迟。

True Peak 为 2.5 ms 前瞻，上限 −0.1 dBFS，附加延迟为 2.5 ms 加过采样延迟。

Modern 与 True Peak 采用前瞻峰值检测，以单一增益曲线缩放整段波形，不产生静态削波谐波。检测为左右声道联动，声像不会因此偏移。

Limiter Oversampling 为限制器独立的过采样设置，与饱和过采样相互独立。Off 与 Clip 不使用过采样，此时该项置灰。

---

## 9　电平表与谐波环

### 9.1　四路电平

上排为输出左右声道，梅红色。

下排为输入左右声道，青绿色。

显示范围约 −60 至 0 dB，检波方式为 RMS，每路带峰值保持尾条。

> 注　满幅正弦读数约 −3.0 dBFS，满幅方波为 0 dBFS，此为 RMS 检波的正确结果。本表非 LUFS 响度计，非过采样真峰值表。最终电平请仍以宿主与导出结果为准。

### 9.2　谐波环

显示值为谐波层 RMS 与干声 RMS 之比，映射至 0 至 100%。

读数为 0% 表示低于显示窗口下限。读数为 100% 表示谐波层 RMS 已达到干声量级。SCHRANZ 模式下该比值无定义，环内显示 N/A。

> 注　本表非谐波占总输出的百分比，也非 THD 测量值。

### 9.3　旁通时的表头

BYP 生效时，电平表继续显示输入信号。

> 注　旁通状态下输入与输出为同一信号，显示输出将失去参考意义。

## 10　预设

### 10.1　格式与位置

预设文件扩展名为 hinj，分 Factory 与 User 两个目录。

本版本与早期版本的预设双向互通，您已有的预设可以直接继续使用。

### 10.2　与全局设置的区别

全部 EQ 与饱和参数属于预设内容。

饱和过采样不属于预设，为本机全局偏好。

显示设置不属于预设，仅影响显示。

INIT 为唯一将全部参数连同过采样一并恢复默认的操作。

## 11　安装

### 11.1　运行条件

需要 64 位系统。

需要支持 VST3、LV2 或 VST2 的宿主。

显示器无特殊要求，高 DPI 环境按设备像素渲染。

### 11.2　安装位置

Linux 下，VST3 放至用户目录的 vst3 子目录，LV2 放至用户目录的 lv2 子目录，VST2 放至用户目录的 vst 子目录。独立程序可直接执行。

Windows 下，VST3 放至通用 VST3 目录，LV2 放至 LV2 搜索路径内，VST2 放至 VstPlugins 目录，独立程序可直接执行。

### 11.3　运行库

Linux 除插件文件外无附加依赖。

Windows 发行包内含编辑器所需运行库。若您使用的是不含运行库的精简包，插件将无法被宿主加载。

> 注　Windows 插件的导入表直接引用运行库，缺失时加载失败，音频不会通过。

### 11.4　卸载

删除 11.2 中所安装的插件文件即可。

用户预设为您自己的文件，不随之删除。

## 12　从哪里开始

四条路径，都不需要您先动 EQ。挑一条最接近您当前需求的即可。

只要厚度而不改音色，选 HARMONIC，Drive 设 2 至 3，Harmonics 设 30% 至 50%，侧链 EQ 保持平直。

需要常规饱和，选 CLASSIC，Drive 设 4 至 6，Harmonics 设 60% 至 80%，再用后置 EQ 修整。

只需处理中央，将 Stereo Mode 设为 Mid，其余照常。

做声音设计，可在 SCHRANZ 下直接用侧链 EQ 深削塑形，或在 HARMONIC 下用高 Q 的 Notch 造共振。

判断手段只有两个：SOLO HARM 听谐波支路，A/B 比两套参数。建议您先把 Drive 与 Harmonics 的关系摸清，再动侧链 EQ——后者改变的是谐波的颜色，不是音量。

## 14　已知限制

- 均衡器节点的悬停数值编辑框，在最后一次界面布局调整后未重新验证。该路径在代码中完整且可编译，但未经实测确认，本版不声称可用。双击切换开关走独立的信号路径，不受此条影响。
- macOS 完全未经测试。
- 窗口尺寸可调为编译期开关，默认关闭。开启后的拉伸行为未在真实宿主中逐项测试。
- 中央谐波环的光晕采用较早的绘制路径，尚未与界面其余部分统一，在低性能机器上可能占用较高资源。

## 附录 A　参数构成

共六十九项，分为三组。

### A.1　全局与饱和

共十九项。

布尔型三项，为旁通、自动增益与独奏谐波。

浮点型八项，为输入增益、输出增益、驱动、谐波混合量、偶次奇次倾向、谐波增益、去强调与空气保护。

枚举型八项，为立体声模式、驱动类型、驱动模式、饱和过采样、侧链量程、后置量程、限制器模式与限制器过采样。

### A.2　侧链 EQ

共二十五项，即五带乘五项。

第 1 带至第 5 带，参数 ID 以 sc1 至 sc5 为前缀。

每带包含频率、增益、Q、类型与开关五项。

### A.3　后置 EQ

共二十五项，即五带乘五项。

第 1 带至第 5 带，参数 ID 以 pq1 至 pq5 为前缀。

每带包含频率、增益、Q、类型与开关五项。
