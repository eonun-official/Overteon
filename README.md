# Overteon 使用说明书

版本 0.9.20

---

## 欢迎您使用 Overteon

这是一款把侧链均衡、饱和、谐波提取与后置均衡放进同一条信号拓扑的音频效果器。

您大概见过不少饱和插件：把一个信号推进非线性曲线，然后按比例混回干声。这样
做当然有效，但结果是**音色跟着一起变了**——您想要的是厚度，拿到的却是一个新
的声音。

Overteon 换了一个思路。它先用一条均衡决定饱和器**听到**什么，再从饱和结果里
只取出**新产生的谐波**，把这一层叠回您的干声。干声本身没有被均衡，也没有被
染色，它只是变得更厚、更有空气感、更有颗粒。

您可以把它当作一台常规饱和器使用，也可以只取它最独特的那一面：**只加谐波，
不改音色**。

## 1　概述

### 1.1　用途

Overteon 是音频效果插件，将侧链均衡、饱和、谐波提取与后置均衡置于同一条
信号拓扑中，可作为常规饱和器使用，也可仅将新产生的谐波叠加至干声。

### 1.2　信号流

```
输入 ──────────────────────────────────────────→ 干声支路 ─┐
                                                          ├→ 求和 → 后置 EQ → 输出
输入 → 侧链 EQ → 过采样饱和 → 提取谐波 → 去强调 ──────────┘
```

干声支路不经过侧链 EQ，也不经过其反向均衡。两路在求和点之前保持延迟对齐。

### 1.3　基本关系

```
输出 = 干声 + HARMONICS × 去强调后的谐波层
```

由式可见，`HARMONICS` 控制谐波层的叠加量，`DRIVE` 控制谐波层自身的强度。

> 注 1　侧链 EQ 改变的是谐波层的频率分布，不是干声的频率响应。
>
> 注 2　默认工作模式为 HARMONIC。

## 2　三种工作模式

模式由底部 **MODE** 选择。三者之间的差别是**拓扑**，不是预设强度——切换模式
会真正改变信号经过哪些环节，这也是 Overteon 值得您花几分钟熟悉的地方。

### 2.1　HARMONIC（默认）

```
输入 ─────────────────────────────────────→ 对齐干声 ─┐
                                                      ├→ 后置 EQ → 输出
输入 → 侧链 EQ → 过采样饱和 → 提取谐波 → 去强调 ──────┘
```

侧链 EQ 与后置 EQ 均参与。`HARMONICS` 表示谐波层叠加量。

这是 Overteon 的核心模式。您想要的"加厚但不改音色"，就在这里。

### 2.2　CLASSIC

```
输入 → 饱和 → 按 HARMONICS 与干声混合 → 后置 EQ → 输出
```

侧链 EQ 不参与处理，面板置灰。`HARMONICS` 表示湿声与干声的混合比。

需要一台用起来顺手的常规饱和器时，选它。

### 2.3　SCHRANZ

```
输入 → 侧链 EQ → 输出增益 / AUTO GAIN → 输出
```

输出为侧链 EQ 之后、饱和器之前的信号。饱和器与后置 EQ 均不参与，面板置灰。
本模式下谐波比例无定义，谐波环显示 `N/A`。

> 注　`HARM GAIN`、`DE-EMPH`、`AIR PROTECT`、`SOLO HARM` 仅在 HARMONIC 模式
> 下作用于谐波支路。

## 4　操作

### 4.1　旋钮

| 动作 | 结果 |
|---|---|
| 上下拖动 | 连续调整，向上增大 |
| 滚轮 | 每格约 4% 行程；离散参数每格切换一项 |
| Shift + 拖动或滚轮 | 细调，约为常态步长的四分之一 |
| 双击 | 恢复该参数默认值 |

> 注　滚轮在指针位于旋钮圆环上时生效，不会误动旁边相邻的旋钮。

### 4.2　下拉菜单与开关

单击展开选项，单击选项完成选择。开关类控件单击即切换。

### 4.3　均衡器节点

| 动作 | 结果 |
|---|---|
| 拖动节点 | 改变频率；Bell 与 Shelf 类同时改变增益 |
| 滚轮 | 改变 Q 值 |
| Shift + 滚轮 | 以细步改变 Q 值 |
| 悬停节点 | 打开数值编辑框 |
| 双击节点 | 切换该带开关状态 |
| 双击空白画布 | 在该频率位置启用一个未使用的节点 |
| 右键节点 | 打开该带菜单（类型、移除） |

> 注　Cut 与 Notch 类节点无增益，拖动时仅改变频率。

### 4.4　表头

| 控件 | 动作 |
|---|---|
| BYP | 旁通整个插件 |
| A / B | 左键：选中该槽；右键：将该槽内容复制到另一槽 |
| INIT | 全部参数复位为默认值 |
| 名称标识 | 悬停显示提示；单击打开关于面板 |

A/B 两槽各存一份完整参数快照，切换为互相比较，非单向递进。调参时请善用它——
您会发现，判断一个改动是否有益，最快的方法永远是跟另一个版本比。

### 4.5　显示设置

指针悬停于中央谐波环时，环体转为绿色，百分比文字替换为 `SETTINGS`；此时单击
打开显示设置面板。

面板内对三个表分别设置：

| 设置 | 选项 |
|---|---|
| Detector | `RMS` / `TRUE PEAK` |
| Interpolation | `SMOOTH` / `NONE` |

> 注　以上为显示设置，不参与音频处理，因此不作为可自动化参数暴露给宿主。

## 5　参数参考

### 5.1　全局

| 参数 | 范围 | 默认 |
|---|---|---|
| Bypass | 关 / 开 | 关 |
| Input Gain | −24 … +24 dB | 0 dB |
| Output Gain | −24 … +24 dB | 0 dB |
| Auto Gain | 关 / 开 | 关 |
| Stereo Mode | Stereo / Mid / Side / M/S | Stereo |

### 5.2　饱和

| 参数 | 范围 | 默认 |
|---|---|---|
| Drive | 0.00 … 10.00 | 0.00 |
| Drive Type | Tanh / Tube / Tape | Tanh |
| Oversampling | 2x / 4x / 8x / 16x / 32x | 4x |

三种类型为插件内不同的非线性曲线，非特定硬件建模：

| 类型 | 特性 |
|---|---|
| Tanh | 平滑，对称 |
| Tube | 含不对称成分，与 Even/Odd 配合使用 |
| Tape | 较柔和，瞬态收束 |

### 5.3　谐波

| 参数 | 范围 | 默认 |
|---|---|---|
| Harmonics Mix | 0 … 100% | 100% |
| Even / Odd | −100% … +100% | 0% |
| Harmonics Gain | −12 … +24 dB | 0 dB |
| De-Emphasis | 0 … 100% | 100% |
| Air Protect | 2 k … 20 kHz | 20 kHz（关） |
| Solo Harmonics | 关 / 开 | 关 |

`Even / Odd` 负值偏偶次谐波，正值偏奇次谐波，居中原样。

`De-Emphasis` 为可逆侧链节点的反向均衡程度，100% 为完整去强调。

`Air Protect` 仅对谐波支路做低通，不作用于干声——您的高频空气感因此得以保留。

`Solo Harmonics` 关闭干声支路，仅输出谐波层，是检查谐波内容的直接手段。

### 5.4　均衡器（每带）

侧链 EQ 与后置 EQ 各 5 带，每带 5 个参数。

| 参数 | 范围 | 默认 |
|---|---|---|
| Freq | 5 Hz … 20 kHz | 见附录 B |
| Gain | −12 … +12 dB | 0 dB |
| Q | 0.1 … 6.0 | 0.707 |
| Type | 8 种，见 6.1 | 见附录 B |
| On | 关 / 开 | 开 |

### 5.5　量程

| 参数 | 选项 | 默认 |
|---|---|---|
| SC EQ Range | ±12 / ±24 / ±48 / ±90 dB | ±12 dB |
| Post EQ Range | ±3 / ±6 / ±12 / ±30 dB | ±12 dB |

### 5.6　限制器

| 参数 | 选项 | 默认 |
|---|---|---|
| Limiter Mode | Off / Clip / Modern / True Peak | Modern |
| Limiter Oversampling | 2x / 4x / 8x / 16x | 4x |

> 注　全部 69 个参数的完整列表见附录 A。可自动化参数的数量与索引为插件接口的
> 组成部分，新参数一律追加在既有参数之后，因此旧工程不会错位。

## 6　均衡器

### 6.1　类型

| 类型 | 说明 |
|---|---|
| Bell | 峰值型 |
| Notch | 窄带衰减 |
| Low Shelf | 低架 |
| High Shelf | 高架 |
| Low Cut 12 | 12 dB/oct 低切 |
| Low Cut 24 | 24 dB/oct 低切 |
| High Cut 12 | 12 dB/oct 高切 |
| High Cut 24 | 24 dB/oct 高切 |

任一节点可设任一类型，频率范围覆盖全频段。每带另带独立开关，关闭的节点以
空心绘制，其频率、增益、Q 与类型均保留，重新开启即恢复原状态。

### 6.2　侧链 EQ

在 HARMONIC 模式下，侧链 EQ 决定饱和器的输入频率分布。提升某频段将增加该频段
产生的谐波量；衰减则减少。

请留意这一点：**您在侧链 EQ 上做的塑形，听见的是谐波的颜色变化，不是干声的
频响变化**。这是 Overteon 与其他饱和器最不一样的地方，也是它最值得玩的地方。

> 注　高 Q 值配大幅衰减时出现振铃，为滤波器响应的固有性质。需要避免时降低 Q
> 值，或改用 Shelf 与 Cut 类型。

### 6.3　后置 EQ

作用于求和之后的完整信号，用于最终修整。CLASSIC 与 HARMONIC 模式下有效，
SCHRANZ 模式下不参与。

## 7　立体声与过采样

### 7.1　立体声模式

| 选项 | 行为 |
|---|---|
| Stereo | 左右声道分别处理 |
| Mid | 仅保留处理后的中央成分，两侧回退至干声 |
| Side | 仅保留处理后的两侧成分，中央回退至干声 |
| M/S | 中央与两侧均在 M/S 域处理后解码 |

处理人声、底鼓、贝斯时，`Mid` 常常比任何均衡都有效——它让您只给中央加厚度，
两侧原封不动。

### 7.2　饱和过采样

选项 2x / 4x / 8x / 16x / 32x，默认 4x。倍率越高，混叠越低，延迟与运算量越大。
切换后插件向宿主更新延迟报告，宿主需启用延迟补偿。

> 注　饱和过采样为本机全局偏好，不属于预设内容。加载预设不改变当前选择。

## 8　输出限制器

位于后置 EQ、`OUTPUT` 与 `AUTO GAIN` 之后。

| 模式 | 行为 | 附加延迟 |
|---|---|---|
| Off | 完全旁通 | 0 |
| Clip | 软膝削波，−1 dBFS 起弯，上限 0 dBFS | 0 |
| Modern | 1.5 ms 前瞻，程序相关释放 | 1.5 ms + 过采样延迟 |
| True Peak | 2.5 ms 前瞻，上限 −0.1 dBFS | 2.5 ms + 过采样延迟 |

Modern 与 True Peak 采用前瞻峰值检测，以单一增益曲线缩放整段波形，不产生静态
削波谐波。检测为左右声道联动，声像不会因此偏移。

`Limiter Oversampling` 为限制器独立的过采样设置，与饱和过采样相互独立。
Off 与 Clip 不使用过采样，此时该项置灰。

> 注　模式为 Off 时，输出不再保证低于 0 dBFS。

## 9　电平表与谐波环

### 9.1　四路电平

| 位置 | 含义 | 颜色 |
|---|---|---|
| 上排 | OUT L / R | 梅红 |
| 下排 | IN L / R | 青绿 |

显示范围约 −60 … 0 dB，检波方式为 RMS，每路带峰值保持尾条。

> 注　满幅正弦读数约 −3.0 dBFS，满幅方波为 0 dBFS，此为 RMS 检波的正确结果。
> 本表非 LUFS 响度计，非过采样真峰值表。最终电平请仍以宿主与导出结果为准。

### 9.2　谐波环

显示值为谐波层 RMS 与干声 RMS 之比，映射至 0 … 100%。

| 读数 | 含义 |
|---|---|
| 0% | 低于显示窗口下限 |
| 100% | 谐波层 RMS 达到干声量级 |
| `N/A` | 当前模式下无定义（SCHRANZ） |

> 注　本表非"谐波占总输出的百分比"，非 THD 测量值。

### 9.3　旁通时的表头

BYP 生效时，电平表继续显示输入信号。

> 注　旁通状态下输入与输出为同一信号，显示输出将失去参考意义。

## 10　预设

### 10.1　格式与位置

预设文件扩展名为 `.hinj`，分 `Factory` 与 `User` 两个目录。本版本与早期版本的
预设双向互通，您已有的预设可以直接继续使用。

### 10.2　与全局设置的区别

| 项目 | 是否属于预设 |
|---|---|
| 全部 EQ 与饱和参数 | 是 |
| 饱和过采样 | 否，本机全局偏好 |
| 显示设置 | 否，仅显示 |

`INIT` 为唯一将全部参数（含过采样）恢复默认的操作。

## 11　安装

### 11.1　运行条件

| 项目 | 要求 |
|---|---|
| 体系结构 | 64 位 |
| 宿主 | 支持 VST3、LV2 或 VST2 |
| 显示器 | 任意；高 DPI 按设备像素渲染 |

### 11.2　安装位置

| 格式 | Linux | Windows |
|---|---|---|
| VST3 | `~/.vst3/Overteon.vst3` | `C:\Program Files\Common Files\VST3\` |
| LV2 | `~/.lv2/Overteon.lv2` | LV2 搜索路径内 |
| VST2 | `~/.vst/Overteon.so` | `C:\Program Files\VstPlugins\Overteon.dll` |
| 独立程序 | 直接执行 | 直接执行 |

### 11.3　运行库

Linux 除插件文件外无附加依赖。Windows 发行包内含编辑器所需运行库；若使用不含
运行库的精简包，插件将无法被宿主加载。

> 注　Windows 插件的导入表直接引用运行库，缺失时加载失败，音频不会通过。

### 11.4　卸载

删除 11.2 中所安装的插件文件。用户预设为您自己的文件，不随之删除。

## 12　从哪里开始

四条路径，都不需要您先动 EQ。挑一条最接近您当前需求的即可。

| 您想要 | 建议设置 |
|---|---|
| 只要厚度，不改音色 | HARMONIC，`DRIVE` 2–3，`HARMONICS` 30–50%，侧链 EQ 保持平 |
| 常规饱和 | CLASSIC，`DRIVE` 4–6，`HARMONICS` 60–80%，用后置 EQ 修整 |
| 只处理中央 | `STEREO` = Mid，其余照常 |
| 做声音设计 | SCHRANZ 直接用侧链 EQ 深削塑形，或 HARMONIC 里用高 Q 的 Notch 造共振 |

判断手段只有两个：**SOLO HARM** 听谐波支路，**A/B** 比两套参数。建议您先把
`DRIVE` 与 `HARMONICS` 的关系摸清，再动侧链 EQ——后者改变的是谐波的颜色，
不是音量。

## 14　已知限制

1. 均衡器节点的悬停数值编辑框，在最后一次界面布局调整后未重新验证。该路径
   在代码中完整且可编译，但未经实测确认，本版不声称可用。双击切换开关走独立
   信号路径，不受此条影响。
2. macOS 完全未经测试。
3. 窗口尺寸可调为编译期开关，默认关闭。开启后的拉伸行为未在真实宿主中逐项测试。
4. 中央谐波环的光晕采用较早的绘制路径，尚未与界面其余部分统一，在低性能机器上
   可能占用较高资源。
